# 🌸 Meu Portfólio — HTML5

## 📖 Sobre a Atividade

Esta atividade consiste na criação de uma página de **portfólio pessoal** utilizando **HTML5**, com uma estrutura organizada, semântica e funcional.

O objetivo foi desenvolver uma página contendo informações pessoais, habilidades, projetos e um formulário de contato, aplicando corretamente as principais tags do HTML5.

---

## 🎯 Objetivos

- Criar uma página HTML5 estruturada e semântica;
- Utilizar tags como `header`,`main`, `section` e `footer`;
- Criar links internos utilizando âncoras;
- Inserir uma imagem de perfil com dimensões de **150x150 pixels**;
- Desenvolver uma tabela para apresentar projetos;
- Criar um formulário de contato;
- Utilizar `fieldset` e `legend`;
- Aplicar estilização básica com CSS interno.

---

## 💻 Tecnologias Utilizadas

- HTML5
- CSS Interno
- Visual Studio Code

## 🧩 Estrutura da Página

### 👩‍💻 Sobre Mim

A seção apresenta:

- Foto de perfil (150x150 pixels);
- Breve apresentação;
- Lista de habilidades.

### 📁 Meus Projetos

Foi criada uma tabela utilizando:

- `table`
- `thead`
- `tbody`
- `tr`
- `th`
- `td`

A tabela apresenta:

| Projeto | Tecnologias | Status |
|----------|------------|---------|
| Sistema de Chamados | HTML, CSS | Concluído |
| Loja Smart Watch | HTML, CSS, JavaScript | Concluído |
| Jogo Space Invaders | HTML, CSS, JavaScript | Em andamento |

### 📩 Entre em Contato

O formulário utiliza:

- `form`
- `fieldset`
- `legend`
- `label`
- `input`
- `select`
- `textarea`
- `button`

---

## 🎨 Estilização

Foi aplicada uma cor de fundo rosa claro utilizando CSS interno:

```css
body {
    background-color: #ffeef7;
}
```

## 🔗 Navegação

O menu utiliza links internos:

